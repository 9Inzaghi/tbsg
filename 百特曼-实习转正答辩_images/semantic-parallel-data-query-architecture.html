LAYER 1 · 输入契约与模式分流层
📥
输入契约（Input Contract）
必传参数 · 查询元素结构 · 全局可选参数 · 模式判定

🔑 必传参数

consumeDatasetId（数据集 ID）+ queries[]（查询配置数组）；简单模式则由 simpleQuery 触发，必传 consumeDatasetId + metrics

🧾 queries[] 元素字段

queryId / queryType（data｜metadata）/ metrics（;分隔）/ timeRange / dimensions / filters / cycleType / statisticType / orderBy / limit / metadataTool / metadataQuery

⚙️ 全局可选参数

maxConcurrency（默认 3，上限 5）· circuitBreaker（默认 3，0 禁用）· mergeSameCondition（默认 true）· notifyOnError（默认 true）· dcsSign · traceQuery · skillName

⚡ 简单模式参数

simpleQuery（触发条件，仅作上下文标识与 trace 描述，不参与取数）+ maxMetricsPerQuery（默认 5，0 禁用拆分）；queries / mergeSameCondition / traceQuery / notifyOnError 在此模式下不生效

⚡
路径 A · 简单单次取数
触发：simpleQuery 存在 且 指标数 N ≤ maxMetricsPerQuery（默认 5）
Step S1 单次取数（可重试 1 次）→ Step S2 直接输出，随后截断（停止阅读 SKILL.md）
不创建链路追踪，不执行合并 / 分批并行 / 熔断 / 钉钉通知；最轻量的快速路径。
快速路径 单次调用 直接输出 无 trace
🔀
路径 B · 简单并行模式
触发：simpleQuery 存在 且 N > maxMetricsPerQuery
SP1 指标拆分（每 5 个一组）→ SP2 create-trace → SP3 分批并行取数 → SP4 直接输出
复用分批并行 / 失败重试 / 熔断机制；跳过同条件合并、结构化组装与钉钉通知；各组继承全部其他参数，仅 metrics 不同。
指标拆分 链路追踪 分批并行 直接输出

LAYER 2 · 核心执行机制层（6 大能力）
🔀
同条件查询合并
Step 2.5 · 仅结构化模式
纯内存预处理：consumeDatasetId / timeRange / dimensions / filters / cycleType / statisticType / orderBy / limit 八字段完全相同的 data 查询合并为一次调用，metrics 用 ; 拼接去重，记录 mergedFrom；metadata 查询不参与。
默认开启 减少请求数 可关闭
⚙️
分批并行执行
Step 3b · 结构化 + 简单并行
batch 大小 = min(maxConcurrency, 5)，默认 3；同 batch 内多个 aone-kit Bash 调用在同一个 assistant message 中并行发起，batch 之间串行等待，兼顾吞吐与平台压力。
batch=3 默认 批内并行 批间串行
🔁
失败重试
Step 3c · error-taxonomy 判定
仅可重试错误（TIMEOUT / NETWORK_ERROR / PLATFORM_INTERNAL_ERROR）以完全相同参数重试 1 次，输出标记 retried: true；重试占用当前 batch 的并行槽位；不可重试错误直接返回结构化错误。
最多 1 次 同参数 retried 标记
🛑
熔断机制
Step 3d · 本 skill 特色能力
维护连续失败计数器：成功即清零，失败累加；连续失败达到 circuitBreaker（默认 3，传 0 禁用）时中止剩余 data 查询，标记 CIRCUIT_BREAKER_TRIGGERED / skipped: true，已完成查询不受影响；仅作用于 data 查询。
连续 3 次 防无效堆积 可禁用
🔗
链路追踪
Step 1 / SP2
create-trace 生成全局 traceId，同一轮所有查询共用；每次取数通过 --header 'EagleEye-TraceId:<traceId>' 透传，产出置信度报表链接 traceReportUrl，便于多批次问题排查。
traceId 共用 EagleEye 透传 置信度报告
🏷️
错误分类与提取
references/error-taxonomy.md
11 种错误代码枚举，统一输出 code / rawMessage / extracted / suggestion / retryable；结构化提取未绑定字段（unboundMetrics）、权限信息（sceneName / applyUrl）、非法字段（invalidFields）等。
11 类错误 结构化提取 重试判定
🧬 queryMode 固定

请求固定 queryMode: "semantic"，指标 / 维度支持中文语义名与英文 code 直传

🔢 limit 必填约定

上游未传 limit 时必须显式填充 9999，不可省略、不可传 null

⚠️ orderBy × limit 交互风险

带维度展开且无 orderBy 时，limit 截断的是平台内部顺序，并非 TOP N；排名类需求必须显式传 orderBy

LAYER 4 · 语义平台层
🏛️
DIC 语义平台（Semantic Platform）
实际执行语义查询的后端服务
按 consumeDatasetId 定位消费数据集，在语义层解析指标 / 维度并执行计算。返回 result 数据数组、assistantMessage 附加说明与 queryResultId 结果存储 ID；链路追踪信息汇入置信度报表（traceReportUrl）。查询成功但结果为空时返回 success: true, isEmpty: true（EMPTY_RESULT，非真正错误）。
queryMode=semantic 中文语义名 / 英文 code 双支持 queryResultId 结果存储 置信度报表 dcsSign 数据集鉴权
输出契约与错误通知

🧩 结构化模式输出（JSON）

路径 C 专用 · 与上游 skill 程序化对接
  • 顶层：traceId / traceReportUrl / totalQueries / successCount / failureCount / circuitBreakerTriggered / notificationSent
  • results[]：queryId / dsl（完整请求参数）/ success / result 数据数组 / totalCount / queryResultId / assistantMessage / retried / mergedFrom / skipped
  • 失败项含结构化 error：code / rawMessage / extracted / suggestion / retryable
  • 空结果：success: true + isEmpty: true

⚡ 简单模式输出（直接呈现）

路径 A / B 共用 · 无结构化 JSON 外壳
  • 成功：提取 result 数据，结合 assistantMessage，用自然语言或表格直观呈现
  • 多行数据以表格呈现；简单并行模式各组数据按维度合并为一张表
  • 部分失败：成功组正常呈现，失败组说明失败指标与原因（含重试 / 熔断状态）
  • 不输出 traceId / queryResultId / mode / success 等元信息字段
  • 不执行钉钉错误通知（Step 6）

🔔 Step 6 · 钉钉错误通知

仅结构化模式 · notifyOnError 默认 true 且存在失败时
  • 配置：references/dingtalk-config.json 的 webhookUrl + signSecret（HMAC-SHA256 签名）
  • 识别查询人：qoderwork profile 邮箱前缀，失败显示"未知用户"
  • Markdown 告警：成功/失败计数 + 每个失败查询的指标、维度、错误码、错误信息（截取 200 字符）、建议
  • 附 Trace 置信度报表链接；通知失败不影响主流程（notificationSent: false）
  • 配置未设置时跳过（notificationSkipped: "config_not_set"）
错误分类速查（references/error-taxonomy.md）
错误代码 可重试 触发条件与说明
TIMEOUT是查询超时；建议缩小时间范围或减少维度
NETWORK_ERROR是Bash aone-kit 调用网络故障（ECONNREFUSED / ETIMEDOUT / fetch failed）
PLATFORM_INTERNAL_ERROR是success: false 且非特定错误，平台内部异常，重试可能恢复
NOT_BOUND_TO_PHYSICAL_TABLE否指标/维度未绑定物理表；提取 unboundMetrics / unboundDimensions
PERMISSION_DENIED否鉴权失败 / 无场景访问权限；提取 sceneName / sceneAdmin / applyUrl
INVALID_METRIC_OR_DIMENSION否字段名不匹配（未找到 / 不存在 / 无法识别）；提取 invalidFields
INVALID_PARAM否参数值不合法（如 cycleType 值错误）
DATASET_NOT_FOUND否数据集 ID 不存在，检查 consumeDatasetId
EMPTY_RESULT否成功但结果为空（success: true, isEmpty: true），非真正错误
CIRCUIT_BREAKER_TRIGGERED否熔断跳过（本 skill 新增），skipped: true，建议检查语义平台状态
UNKNOWN否无法归类，查看 rawMessage 判断
